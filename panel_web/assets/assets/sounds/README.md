# Sonidos de Alerta

Este directorio contiene los archivos de audio para las alertas de la aplicación.

## Archivo requerido:
- `alert.mp3`: Sonido de alerta para nuevos dispositivos detectados.

## Instrucciones:
1. Coloca un archivo `alert.mp3` en este directorio para habilitar el sonido de alerta.
2. Si no se proporciona el archivo, la aplicación funcionará sin sonido (solo vibración).
3. Se recomienda usar un sonido corto (1-2 segundos) de alerta de seguridad.
